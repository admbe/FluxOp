# Governed cloud cost intelligence

Flux brings cloud inventory, cost, telemetry, optimization opportunities, and
financial planning into one governed FinOps workspace. Recommendations retain
their source evidence and require explicit human approval before execution.

> **2.0.0 · ca66a85** — `frontend/dist/version.json` + `version.json` stamped at build time from `$(Build.SourceVersion)`; `settings.build_commit` (`api/config.py`) → `GET /api/health` (`commit`) and `GET /api/session` (`build` + `dataCurrency`); Shell header chip (click-to-copy) + footer `v2.0.0 · ca66a85`. Pipeline step "Stamp build version" is the source of truth.
