# Exact-pinned, not a range: DuckDB is a stateful on-disk storage engine,
# and the mutable flux.duckdb file is written across many separate deploys
# over its lifetime. A floating range lets consecutive deploys silently
# resolve to different patch builds, and a newer engine checkpointing
# structures an older one wrote can corrupt the file outright --
# "TransactionException: ... invalid node type for TransformToDeprecated"
# is DuckDB's own signature for exactly this. Confirmed as the likely root
# cause of repeated production corruption incidents (2026-07-26, -29, -30 x2)
# that were each patched as isolated recoveries without pinning this.
# 1.5.1 additionally raises an internal vector-index assertion in the
# governed opportunity/valuation CTEs, ruling it out separately. Bump this
# deliberately, verify the full reporting suite, and take a fresh approved
# snapshot immediately after -- never let it float.
